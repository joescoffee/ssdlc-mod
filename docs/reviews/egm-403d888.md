## 結論

**`FIX-BEFORE-MERGE`：沒有 Critical，也沒有惡意內容。** 在 Claude Code 上可以安心用 EGM 審查自己或可信任的 repo。
**但不要對不受信任的 repo 執行 `/egm-bootstrap`**，原因是 F1、F2：它會執行 repo 自己設定的 formatter，而且 orchestrator 一邊讀不受信任的內容、一邊握有 Bash/Write。這種情況請改用 `/ssdlc:safe-bootstrap`。

## 已確認沒有問題
- 沒有 hooks、`.mcp.json` 或 commands；打包程式會拒絕 hooks 與 MCP（`tests/unit/test_packaging.py:235-264`）。
- 7 個技能都設了 `disable-model-invocation: true`。bootstrap 偵測到的測試指令只寫進 README，不會被執行。
- 所有 workflow 的 actions 都釘選 commit SHA、`persist-credentials: false`、權限最小化。`pr-scope-advisory.yml` 雖使用 `pull_request_target`，但不 checkout PR 程式碼，也沒有 script injection。
- `scripts/pack_plugin.py` 有檢查 symlink 與 `is_relative_to`，只建立 zip、不解壓，沒有 zip-slip。`prepare_release.py` 沒有呼叫 subprocess。
