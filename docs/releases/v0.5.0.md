## ssdlc v0.5.0

Secure SDLC mod for Claude Code: security review, AI/agent review (OWASP LLM Top 10 2026, Agentic Top 10 2026, MIT AI Risk Repository), a pre-PR gate, a vulnerability-fix workflow, and read-only reviewer agents enforced by a guard hook.

### Install
```
claude plugin install ssdlc --marketplace joescoffee/ssdlc-mod
```
Start with the [Beginner's Guide](https://github.com/joescoffee/ssdlc-mod/blob/main/docs/manual/README.en.md).

### What's in it
- **Six skills**: `/ssdlc:security-review`, `/ssdlc:ai-security-review`, `/ssdlc:security-gate`, `/ssdlc:vuln-fix`, `/ssdlc:safe-bootstrap`, `/ssdlc:rule-from-finding`.
- **Review mode** — type `ssdlc review-mode on|off|status` (works in the Claude app; `/ssdlc-review-mode` in a terminal): the main session may run only exact, non-executing command forms, has no network, writes only report files and may spawn only ssdlc reviewers. Only a person can switch it off.
- **Guard hook for reviewer agents**: Read/Grep/Glob only; credential stores blocked (case-insensitive, symlinks resolved); an **allow-list** limited to the paths named in the dispatching prompt; **tripwires** delivered to the main session as BLOCK alerts; a **liveness check** (`mcp__ssdlc__guard_log`: version + rule self-test) that every skill runs before spawning reviewers; cross-session history.
- **Scanner** (`scripts/gate_scan.py`, standard library only): secrets, dangerous code, Unicode-tag smuggling (hidden text decoded), model supply chain, agent approval bypass and wildcard allow-lists, MCP config (unpinned packages, inline secrets, plaintext transport), executable `.git/config` keys; every finding tagged with CWE / `LLMnn:2026` / `ASInn`; markers ignored by default; exit 3 = INCOMPLETE.
- **References** (CC BY-SA 4.0): OWASP 2026 review checklist, MIT AI Risk Repository SSDLC triage, rules for untrusted repositories.
- **Bilingual docs** (English / 繁體中文): README, Beginner's Guide, strategy, self-review, EGM review, threat model report, mind map.

### Verified
- 53 unit tests and 28 hook tests pass; `claude plugin validate` passes.
- Verified live in the Claude app: review mode blocks `curl`; the reviewer allow-list allows in-scope reads and refuses out-of-scope and credential reads; the tripwire alert reaches the main session; `guard_log` reports `selfTest.pass: true`.

### Case study
A read-only review of `google/elephant-goldfish-model` @ `403d888` found 5 Medium and 8 Low/Info issues, reported upstream as [#261](https://github.com/google/elephant-goldfish-model/issues/261) and [#262](https://github.com/google/elephant-goldfish-model/issues/262).

### Known limitations
Review mode must be switched on manually; the reviewer allow-list is derived from the dispatching prompt; TOCTOU and hard links need an OS-level sandbox; the scanner is a code-hygiene check, not a runtime filter. See the README.

## 繁體中文

ssdlc 是 Claude Code 的安全軟體開發生命週期外掛：安全審查、AI／代理審查（OWASP LLM Top 10 2026、Agentic Top 10 2026、MIT AI Risk Repository）、PR 前閘門、漏洞修復流程，以及由守門 hook 強制的唯讀審查代理。

### 安裝
```
claude plugin install ssdlc --marketplace joescoffee/ssdlc-mod
```
請從[新手操作手冊](https://github.com/joescoffee/ssdlc-mod/blob/main/docs/manual/README.md)開始。

### 內容
- **六個技能**：`/ssdlc:security-review`、`/ssdlc:ai-security-review`、`/ssdlc:security-gate`、`/ssdlc:vuln-fix`、`/ssdlc:safe-bootstrap`、`/ssdlc:rule-from-finding`。
- **審查模式**：輸入一般訊息 `ssdlc review-mode on|off|status`（Claude app 可用；終端機也可用 `/ssdlc-review-mode`）。主 session 只能執行精確、不執行程式的命令形式；不能上網；只能寫報告檔；只能派 ssdlc 審查員；只有使用者能關閉。
- **審查代理守門 hook**：只能用 Read/Grep/Glob；擋憑證位置（不分大小寫、解析 symlink）；**白名單**只限派遣 prompt 指名的路徑；**tripwire** 以 BLOCK 警報傳回主 session；**存活檢查**（`mcp__ssdlc__guard_log`：版本與規則自我檢查），每個技能派審查員前都先確認；跨 session 歷史紀錄。
- **掃描器**（`scripts/gate_scan.py`，只用標準函式庫）：secrets、危險程式、Unicode tag 隱寫（解碼隱藏文字）、模型供應鏈、代理核准繞過與萬用允許清單、MCP 設定（未鎖版本、內嵌密鑰、明文傳輸）、`.git/config` 可執行設定；每筆發現標 CWE／`LLMnn:2026`／`ASInn`；allow 標記預設忽略；結束碼 3＝INCOMPLETE。
- **參考標準**（CC BY-SA 4.0）：OWASP 2026 審查清單、MIT AI Risk Repository SSDLC 分流、不受信任 repo 處理規則。
- **中英雙語文件**：README、新手手冊、改善策略、自我審查、EGM 審查報告、威脅模型報告、心智圖。

### 驗證
- 53 個單元測試、28 個 hook 測試全部通過；`claude plugin validate` 通過。
- 已在 Claude app 實機驗證：審查模式擋下 `curl`；審查員白名單允許範圍內讀取、拒絕範圍外與憑證讀取；tripwire 警報送達主 session；`guard_log` 回報 `selfTest.pass: true`。

### 實戰案例
以唯讀方式審查 `google/elephant-goldfish-model` @ `403d888`，發現 5 項 Medium 與 8 項 Low／Info，已回報上游 [#261](https://github.com/google/elephant-goldfish-model/issues/261)、[#262](https://github.com/google/elephant-goldfish-model/issues/262)。

### 已知限制
審查模式需手動開啟；審查員白名單由派遣 prompt 決定；TOCTOU 與 hard link 需作業系統層沙箱；掃描器是程式碼衛生檢查，不是執行期過濾器。詳見 README。
